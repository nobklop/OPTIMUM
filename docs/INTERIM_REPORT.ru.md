# Промежуточный результат: OPTIMUM 0.2.2

[Скачать и установить Windows x64](https://github.com/nobklop/OPTIMUM/releases/download/v0.2.2/OPTIMUM-0.2.2-Setup-x64.exe)
· [Все версии](https://github.com/nobklop/OPTIMUM/releases)
· [Исходники 0.2.2](https://github.com/nobklop/OPTIMUM/tree/v0.2.2)

После скачивания запустите EXE и нажмите **Установить**: дальше установка, ярлык и запуск автоматические.
Первой установке нужен интернет для аудиодвижка. Администратор, Flutter и Visual
Studio не требуются. Windows может запросить подтверждение неподписанного EXE.
В этом окружении итоговая версия установлена в `D:\OptimumTools\OPTIMUM-app`
и открыта; создан ярлык OPTIMUM.

## Что добавлено и проверено

- **Космос по вашим скриншотам.** 184 звезды вместо 136, пять туманностей в разных
  местах, созвездие, маленькие спутники, блики и дополнительные орбиты главного блока.
- **Плавность.** Убран ограничитель 30 Гц, дававший неравномерный шаг. В profile-замере
  этого ПК движение выросло с 30.06 до 69.12 обновлений/с, интервал p95 сократился с
  45 до 20 мс. Общий замкнутый цикл 90 секунд сохранён, как и уменьшение движения.
- **Библиотека.** JSON-копии плейлистов, избранного, истории и reduced motion;
  восстановление объединяет данные без удаления и дубликатов. Перед обновлением
  старой базы создаётся согласованная SQLite-копия. Аудиофайлы в JSON не входят.
- **Надёжность аудио.** На Windows проверены WAV, MP3, FLAC, OGG и M4A/AAC с русскими
  именами файлов; повреждённый WAV и восстановление воспроизведения. Исправлены
  зависшая загрузка и устаревшая позиция перемотки; next/previous сохраняют паузу.
- **Установка с GitHub.** У каждой опубликованной версии есть кнопка и EXE-установщик,
  контрольная сумма SHA-256, ярлыки, обновление и удаление с сохранением библиотеки.
  Проверены настоящие установки/обновления, хэши каждого файла, защита от отката,
  запуск установленного приложения и удаление. Секреты GitHub не попали в исходники.
- **Рабочая основа приложения.** Локальные файлы/папки, метаданные, поиск, обложки,
  плейлисты, избранное, история, очередь, громкость, shuffle/repeat, полный плеер и
  три оригинальных аудиоэтюда. Проверки воспроизводятся скриптами проекта.

Для 0.2.2 прошли analyzer, все 12 unit/widget tests и нативный Windows audio/UI test.
Отдельная codec matrix ранее прошла на том же аудиобэкенде. Серверное ядро Together
имеет 17 тестов, но сетевое совместное прослушивание ещё не включено.
Реальные кадры Flutter находятся в artifacts; измерения объяснены в PERFORMANCE.md.

## Главный следующий модуль

Зафиксирован ваш сценарий: ссылка Яндекс Музыки / Spotify / SoundCloud → трек или
плейлист в OPTIMUM → воспроизведение → разрешённое скачивание для офлайна.
**В этой версии импорт ссылок ещё не работает.** Нужны проверенные API-интеграции,
авторизация и разрешения провайдера; одного названия или ссылки недостаточно.
Для SoundCloud регистрация API-приложения требует Artist Pro; ответ о доступе
пользователя пока ожидается. Пароли/Client Secret не включаются в приложение или Git.
Подробный план и официальные источники: LINK_IMPORT.ru.md.

Аккаунты, облачная библиотека, друзья, чат, рекомендации, сетевой Together,
мобильные сборки и мобильное фоновое воспроизведение пока не готовы.
