# Промежуточный результат: OPTIMUM 0.3.0

[Скачать и установить Windows x64](https://github.com/nobklop/OPTIMUM/releases/download/v0.3.0/OPTIMUM-0.3.0-Setup-x64.exe)
· [Все версии](https://github.com/nobklop/OPTIMUM/releases)

После скачивания запустите EXE и нажмите **Установить**. Для первого получения
аудиодвижка нужен интернет; Flutter, Visual Studio и администратор не требуются.
Windows может подтвердить запуск неподписанного EXE. Встроенным веб-страницам нужен
Microsoft Edge WebView2 Runtime; если его нет, приложение покажет официальный установщик.

## Добавлено в 0.3.0

- **Вход в сервисы внутри OPTIMUM.** Кнопка **Аккаунты сервисов** вверху открывает
  Яндекс Музыку, SoundCloud и Spotify. Есть официальная форма входа, переход к
  личной библиотеке, назад/обновление и видимый адрес сайта. Сессии хранятся в
  отдельном постоянном веб-профиле. API-ключи и Artist Pro для этого не нужны.
- **Ссылки на музыку.** Сохранение трека, альбома или плейлиста; свои названия,
  поиск, копирование и удаление ссылок. Нормализация обычных URL и ограниченное
  раскрытие известных коротких адресов. Настоящие плееры работают в окне OPTIMUM.
- **Скачивание прямых аудиофайлов.** HTTPS, прогресс, отмена, лимит 512 МБ,
  тайм-ауты, проверка контейнера/длины, очистка .part и атомарное сохранение.
  Файл появляется в локальной библиотеке и воспроизводится без сетевого источника.
  При повторном открытии ссылка отмечает существующий файл на устройстве.
- **Сохранность данных.** SQLite v3 со снимком перед обновлением v1/v2. JSON v2
  включает ссылки/пути скачанных файлов и продолжает читать v1. Повторный импорт
  не создаёт дубликаты. Удаление ссылки не удаляет музыку; удаление локальной записи
  не удаляет файл и очищает её связь со ссылкой.
- **Согласованное воспроизведение.** Открытие сервиса останавливает локальное аудио;
  закрытие экрана уничтожает веб-плеер. Камера, микрофон, геолокация и чтение буфера
  не разрешаются. Пароли/cookies сайтов не читаются кодом и не входят в JSON.

Сохранены прежние функции: файлы/папки, теги и обложки, поиск, лайки, история,
плейлисты, очередь, shuffle/repeat/громкость, мини/полный плеер, три авторских этюда.
Космос: 184 звезды, пять туманностей, детали главного блока, бесшовный 90-секундный
цикл с обновлением на каждом vsync и уменьшением движения.

## Что проверено

Analyzer без замечаний, 17 unit/widget tests, backend 17 tests и ruff.
Настоящая Windows-проверка: три embeds и их play-кнопки; HTML audio play/pause;
HTTPS-загрузка собственного WAV (1344044 bytes) → точное сравнение байтов →
воспроизведение локального файла через libmpv. Повторно прошла прежняя native
проверка паузы/перемотки/очереди/истории/ошибок и интерфейса.

Официальные страницы входа трёх сервисов открылись. На отдельном синтетическом
профиле cookie/localStorage сохранились при закрытии/повторном открытии окна.
Настоящий вход, 2FA и проверку своей личной библиотеки выполняет пользователь;
пароли во время разработки не вводились. Полный перезапуск с реальным аккаунтом
ещё не проверен. Кадры Flutter и подробности: VERIFICATION.md.

## Ограничения

Без входа проверенные Spotify и Яндекс дали примерно 30-секундные фрагменты;
SoundCloud начал поток около 214 секунд. Полный доступ, подписка/страна и поддержка
встроенного браузера определяются сервисом. Google/Apple sign-in может ограничиваться.
Плейлисты и лайки доступны через интерфейс самого сервиса — по вашему выбору они
автоматически не копируются в локальную библиотеку OPTIMUM.

Обычная ссылка на страницу Spotify/Яндекс/SoundCloud не является MP3. Скачиваются
прямые доступные аудиофайлы; защищённые потоки и офлайн-кэши не извлекаются.
JSON не содержит самой музыки. Together, облачный аккаунт OPTIMUM, друзья/чат,
рекомендации, мобильные сборки и мобильные веб-плееры ещё разрабатываются.
