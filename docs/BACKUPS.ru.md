# Резервные копии OPTIMUM 0.2

В настройках доступны **Сохранить копию** и **Восстановить из JSON**.
JSON содержит пути и метаданные треков, избранное, плейлисты с порядком треков,
до 5000 записей истории и настройку уменьшения движения. Самой музыки и обложек
в файле нет. Для переноса на другой компьютер нужно сохранить те же пути аудиофайлов.

Восстановление объединяет данные одной транзакцией. Текущие названия, метаданные
и настройки не перезаписываются; избранное объединяется. Плейлисты сопоставляются
по сохранённому ключу, поэтому одинаковые названия допустимы. Существующий порядок
сохраняется, новые записи добавляются в конец. Повторный импорт копии идемпотентен.
Это перенос/объединение, а не точный откат библиотеки к старому состоянию.

Формат `optimum-library`, версия 1. Максимум 32 МБ, 50000 треков, 5000 плейлистов,
5000 записей истории. Неизвестная версия, неправильные типы, относительные пути,
дубликаты и ссылки на отсутствующие записи отклоняются до изменения базы.
JSON содержит приватные пути и историю; приложение само никуда его не отправляет.

## Миграция и полный откат базы

В 0.2.0 используется схема SQLite v2. Закройте все старые экземпляры приложения
перед запуском. Перед обновлением v1 выполняется SQLite `VACUUM INTO`, создающий
согласованный файл `library.db.before-v2-<UTC microseconds>.db` рядом с базой.
Если копирование не удалось, открытие прерывается до миграции. Оригинальная копия
не изменяется. Путь к рабочей базе показан в настройках.

Для полного отката закройте **все** экземпляры OPTIMUM. Сохраните текущую папку
базы целиком отдельно, включая возможные `-wal`/`-shm`. В исходной папке уберите
текущую базу и её WAL/SHM, скопируйте выбранную автоматическую v1-копию под именем
`library.db`, затем запустите нужную версию приложения. Нельзя оставлять WAL/SHM
от другой версии базы рядом с восстановленным файлом. После отката изменения,
сделанные после момента копии, доступны только в отдельно сохранённой папке.

Автокопия v1 — для отката миграции; JSON — для регулярного переноса библиотеки.
Проверки: `client/test/backup_test.dart`; нативные кнопки — Windows integration.
