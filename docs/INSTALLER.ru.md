# Установка OPTIMUM для Windows

На странице каждой версии GitHub Releases есть кнопка **Скачать и установить**.
Скачайте `OPTIMUM-<версия>-Setup-x64.exe`, запустите и нажмите **Установить**.
Далее автоматически создаются приложение, ярлык рабочего стола и меню «Пуск». Flutter, Visual
Studio и отдельная установка Visual C++ не нужны. Права администратора не требуются.
После установки OPTIMUM открывается автоматически.

С 0.3 встроенным плеерам сервисов нужен Microsoft Edge WebView2 Runtime.
Он не включён в EXE: если отсутствует, приложение показывает официальный установщик.
Локальное воспроизведение работает независимо от WebView2. API-ключи не нужны.

Первая установка требует интернета: установщик получает аудиодвижок из исходного
релиза media-kit на GitHub. SHA-256 архива и самой DLL проверяются до копирования
программы. При сетевой ошибке установка не объявляется завершённой. При обновлении
уже установленный движок с правильной контрольной суммой используется повторно.
Windows может запросить подтверждение запуска: цифровая подпись OPTIMUM пока отсутствует.

Программа размещается в `%LOCALAPPDATA%\Programs\OPTIMUM`. Для автоматизации можно
указать `/DIR="D:\OPTIMUM"`; обычному пользователю параметры не нужны. Обновление
устанавливается поверх старой версии. Закройте OPTIMUM перед обновлением.
Установщик блокирует переход на версию ниже зарегистрированной установленной.

Удаление доступно в **Параметры Windows → Приложения → OPTIMUM** или через ярлык
«Удалить OPTIMUM». Библиотека, настройки и исходные музыкальные файлы сохраняются.
Путь к базе виден в настройках OPTIMUM. Версии до 0.3 не читают обновлённую
базу v3: откат данных описан в BACKUPS.ru.md в исходниках репозитория.

Компоненты и лицензии находятся в папке NOTICES, а лицензии Dart-пакетов — также
в приложении: **Настройки → Лицензии компонентов**. Происхождение аудиодвижка и
правила его получения описаны в `NOTICES/NATIVE_NOTICES.md`.
