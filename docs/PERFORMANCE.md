# Равномерность анимации 0.2.2

Проблема подтверждена в Windows profile mode: общий clock вычислял номер
30-герцового кадра и пропускал другие vsync ticks. На этой машине движение
обновлялось с неравномерными интервалами 30/45 мс. Частоту перестали округлять;
периодические painters получают каждое обновление AnimationController.

Один и тот же настоящий Flutter UI главного экрана, temporary SQLite, без музыки
пользователя и без воспроизведения. Две секунды прогрева, шесть секунд измерения.
Active lifecycle задан явно, чтобы редактор не приостановил фон потерей фокуса.
Rendering backend: Impeller (OpenGLESSDF). Полный Windows/GPU soak не проводился.

JSON: artifacts/cosmic-pacing-before.json и cosmic-pacing-after.json.
Повторение: из client запустить
`flutter run --profile -d windows -t tool/cosmic_benchmark.dart --dart-define=BENCHMARK_NAME=after`.
Benchmark самостоятельно закрывает только свой процесс после сохранения результата.
Для исходного варианта нужно вернуть cap из v0.2.1; не сравнивать debug с profile.

Тест cosmic_motion_test проверяет каждое из 120 обновлений при 60 Гц, freeze при
inactive и reduced motion. cosmic_loop_test сравнивает полный 90-секундный период.
