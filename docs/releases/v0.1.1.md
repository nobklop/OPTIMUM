# OPTIMUM 0.1.1 — оптимизация космического фона

[![Скачать и установить](https://raw.githubusercontent.com/nobklop/OPTIMUM/main/docs/assets/install-windows.svg)](https://github.com/nobklop/OPTIMUM/releases/download/v0.1.1/OPTIMUM-0.1.1-Setup-x64.exe)

Windows 10/11 x64. Скачайте EXE и запустите: приложение установится и создаст ярлык.
Права администратора, Flutter и Visual Studio не нужны. Для первой установки нужен
интернет; Windows может запросить подтверждение запуска неподписанного приложения.

Туманности кэшируются в двух текстурах; фон ограничен 30 Гц и приостанавливается
при неактивном окне. Сохранён замкнутый плавный 90-секундный цикл и reduced motion.
Локальный плеер, импорт, избранное, история и плейлисты работают без аккаунта.

Архивная версия; выбирайте последнюю версию в Releases. Библиотека 0.2.x не
поддерживается. Установщик добавлен позже, код приложения соответствует v0.1.1.
Сценарий упаковки: [packaging/windows](https://github.com/nobklop/OPTIMUM/tree/v0.2.1/packaging/windows).
Аккаунты, импорт ссылок и сетевой Together ещё отсутствуют. SHA-256 — в Assets.
