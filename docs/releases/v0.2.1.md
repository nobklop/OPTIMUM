# OPTIMUM 0.2.1 — более живой космос и простая установка

[![Скачать и установить](https://raw.githubusercontent.com/nobklop/OPTIMUM/main/docs/assets/install-windows.svg)](https://github.com/nobklop/OPTIMUM/releases/download/v0.2.1/OPTIMUM-0.2.1-Setup-x64.exe)

Windows 10/11 x64. Скачайте EXE и запустите — установка, ярлык и запуск автоматические.
Права администратора, Flutter и Visual Studio не нужны. Для первой установки нужен
интернет; Windows может попросить подтвердить запуск неподписанного приложения.

- 184 звезды, пять отдельных туманностей по всему фону.
- В главном блоке появились созвездие, маленькие спутники, блики и дальние орбиты.
- Плавный замкнутый 90-секундный цикл и уменьшение движения сохранены.
- Все функции 0.2.0: локальная музыка, плейлисты, избранное, история и JSON backups.
- Установщик сохраняет библиотеку при обновлении и удалении программы.

Импорт ссылок Яндекс Музыки / Spotify / SoundCloud — следующий отдельный модуль;
в этой версии его ещё нет. Аккаунты и сетевой Together также ещё разрабатываются.
Контрольная сумма EXE находится рядом в Assets (`.sha256`).
