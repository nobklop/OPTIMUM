# OPTIMUM 0.2.0 — резервные копии и надёжность аудио

[![Скачать и установить](https://raw.githubusercontent.com/nobklop/OPTIMUM/main/docs/assets/install-windows.svg)](https://github.com/nobklop/OPTIMUM/releases/download/v0.2.0/OPTIMUM-0.2.0-Setup-x64.exe)

Скачайте и запустите EXE на Windows 10/11 x64. Установка и создание ярлыка
автоматические, без администратора и инструментов разработчика. Для первой установки
нужен интернет; Windows может попросить подтвердить запуск неподписанного EXE.

- JSON-копии библиотеки: плейлисты, избранное, история и настройка движения.
- Восстановление объединяет данные без удаления; повторный импорт не создаёт копии.
- Перед обновлением старой базы создаётся согласованная SQLite-копия.
- Проверены WAV, MP3, FLAC, OGG и M4A/AAC с русскими путями; исправлены загрузка
  повреждённого файла и позиция при перемотке. Next/previous сохраняют паузу.

Аудиофайлы в JSON не включаются. Импорт ссылок из сервисов, аккаунты и сетевой
Together ещё не реализованы. Установщик добавлен после исходного релиза; код
приложения соответствует v0.2.0, [упаковка](https://github.com/nobklop/OPTIMUM/tree/v0.2.1/packaging/windows)
общая для всех версий. SHA-256 установщика — в Assets.
