# OPTIMUM 0.1.0 — первый Windows-прототип

[![Скачать и установить](https://raw.githubusercontent.com/nobklop/OPTIMUM/main/docs/assets/install-windows.svg)](https://github.com/nobklop/OPTIMUM/releases/download/v0.1.0/OPTIMUM-0.1.0-Setup-x64.exe)

Windows 10/11 x64. Скачайте EXE, запустите и нажмите **Установить**: дальнейшие шаги выполняются
автоматически. Администратор, Flutter и Visual Studio не нужны. Для первой установки
нужен интернет; Windows может попросить подтвердить запуск неподписанного приложения.

Первый локальный плеер: импорт файлов/папок, поиск, избранное, история, плейлисты,
очередь, обложки и оригинальные аудиоэтюды. Космический анимированный фон.
Аккаунтов, импорта ссылок и сетевого Together пока нет.

Это архивная версия. Для обычного использования выбирайте последнюю версию в Releases.
0.1.x не читает библиотеку, уже обновлённую в 0.2.x. Общий установщик добавлен
позже, код приложения соответствует тегу v0.1.0. Сценарий сборки установщика:
[packaging/windows](https://github.com/nobklop/OPTIMUM/tree/v0.2.1/packaging/windows).
Контрольная сумма EXE находится рядом в Assets (`.sha256`).
