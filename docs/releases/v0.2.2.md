# OPTIMUM 0.2.2 — плавное движение космоса

[![Скачать и установить](https://raw.githubusercontent.com/nobklop/OPTIMUM/main/docs/assets/install-windows.svg)](https://github.com/nobklop/OPTIMUM/releases/download/v0.2.2/OPTIMUM-0.2.2-Setup-x64.exe)

Windows 10/11 x64. Скачайте EXE, запустите и нажмите **Установить** — дальше всё автоматически.
Администратор, Flutter и Visual Studio не нужны. Первая установка требует интернета.
Windows может попросить подтвердить запуск неподписанного приложения.

Исправлена неравномерная анимация: снято ограничение 30 Гц, движение обновляется
на каждом кадре экрана. В Windows profile-замере частота обновлений выросла с
30.06 до 69.12 в секунду, интервал p95 сократился с 45 до 20 мс. Кэширование,
уменьшение движения и плавный замкнутый 90-секундный цикл сохранены.

Все изменения предыдущих версий: 184 звезды, пять туманностей, созвездие/спутники,
настоящий локальный плеер, плейлисты, избранное, история и JSON backups.

Импорт ссылок Яндекс Музыки / Spotify / SoundCloud пока не реализован; API-доступы
и воспроизведение проверяются отдельно. Аккаунты и сетевой Together ещё разрабатываются.
SHA-256 установщика — в Assets. Детали замеров: docs/PERFORMANCE.md в исходниках.
