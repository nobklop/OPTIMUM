# OPTIMUM 0.3.0 — ссылки и аккаунты сервисов

[![Скачать и установить](https://raw.githubusercontent.com/nobklop/OPTIMUM/main/docs/assets/install-windows.svg)](https://github.com/nobklop/OPTIMUM/releases/download/v0.3.0/OPTIMUM-0.3.0-Setup-x64.exe)

Windows x64: скачайте EXE, запустите и нажмите **Установить**. Дальше приложение,
ярлыки и обновление устанавливаются автоматически, без Flutter и Visual Studio.
Закройте старую версию перед обновлением. Первая установка получает аудиодвижок
из upstream с проверкой SHA-256. Windows может подтвердить запуск неподписанного EXE.

В этой версии:

- **Аккаунты сервисов**: вход и личная библиотека Яндекс Музыки, SoundCloud и Spotify
  внутри OPTIMUM через официальные сайты. Веб-сессия сохраняется в отдельном профиле;
  есть кнопки входа/библиотеки/назад/обновления и видимый адрес страницы.
- **Музыка по ссылке**: сохраняйте треки, альбомы и плейлисты без API-ключей.
  Обычные ссылки нормализуются; поддерживается раскрытие известных коротких ссылок.
  Настоящие встроенные плееры работают внутри приложения.
- **Прямые аудиоссылки**: скачивание с прогрессом и отменой, сохранение в локальную
  библиотеку для прослушивания без сети. Лимит 512 МБ, проверка аудиосигнатуры/длины,
  тайм-ауты и очистка незавершённых файлов.
- **Сохранность библиотеки**: SQLite v3 делает снимок старой базы до обновления.
  JSON v2 включает ссылки и пути скачанных файлов, поддерживает старый JSON v1.
  Удаление ссылки не удаляет музыку. Космический фон и локальный плеер сохранены.

API-ключи и подписка разработчика SoundCloud не нужны. Пароли вводятся на страницах
самих сервисов, не сохраняются в библиотеке и не входят в JSON. Настоящий вход в
личный аккаунт выполняет пользователь; проверка не использовала чужие учётные данные.
Для веб-плееров нужен Microsoft Edge WebView2 Runtime; если его нет, OPTIMUM
показывает официальный установщик. Локальная музыка от него не зависит.

Доступ, полная запись/фрагмент, подписка и поддержка встроенного браузера определяются
сервисом. В проверке без входа Spotify и Яндекс дали примерно 30-секундные фрагменты;
SoundCloud начал поток длительностью около 214 секунд. Обычная ссылка на страницу
не предоставляет MP3 для скачивания. Плейлисты/лайки видны в интерфейсе сервиса и
автоматически не копируются в локальную базу. Вход через Google/Apple может ограничиваться.
Together, облачная синхронизация OPTIMUM и мобильные веб-плееры ещё разрабатываются.

Проверки: analyzer, 17 unit/widget tests, Windows native link/audio/download,
официальные страницы входа и синтетическая сессия при повторном открытии,
регрессия настоящего локального плеера; backend 17 passed и ruff.
