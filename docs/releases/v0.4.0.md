# OPTIMUM 0.4.0 — треки и плейлисты из Яндекса

[![Скачать и установить](https://raw.githubusercontent.com/nobklop/OPTIMUM/main/docs/assets/install-windows.svg)](https://github.com/nobklop/OPTIMUM/releases/download/v0.4.0/OPTIMUM-0.4.0-Setup-x64.exe)

Windows x64: скачайте EXE, запустите и нажмите **Установить**. Закройте старую версию
перед обновлением. Flutter/Visual Studio не нужны; первая установка требует интернета.
Приложение пока без цифровой подписи, поэтому Windows может подтвердить запуск.

- **Добавить текущий трек** — новая кнопка над страницей Яндекс Музыки внутри OPTIMUM.
  Название и ссылка появятся в **Библиотека → По ссылке**.
- **Перенести плейлист** — откройте сам плейлист, «Мне нравится» или альбом Яндекса.
  OPTIMUM проверит весь список и покажет предпросмотр. После подтверждения результат
  появится в **Плейлисты**, с исходным порядком и повторами. Повторный перенос
  обновляет состав существующего плейлиста, сохраняя ваше название.
- **Прикрепить аудиофайл** — свой файл можно связать с треком для локального офлайна.
  Исходный файл остаётся на месте. Для прослушивания всего сервисного списка есть
  **Открыть плейлист в сервисе** с сохранённой веб-сессией.
- **Сохранность данных** — SQLite v4 со снимком перед миграцией; JSON v3 сохраняет
  состав сервисных плейлистов, читает v1/v2. Удаление позиции из плейлиста сохраняет
  остальные вхождения и исходную ссылку. Вход и профиль браузера не сбрасываются.

Перенос сохраняет названия, порядок и ссылки. Защищённое аудио Яндекса не скачивается:
его офлайн-кэш работает только в приложении Яндекса. Для настоящего скачивания в
OPTIMUM поддерживаются прямые HTTPS-ссылки на доступные аудиофайлы. Для Spotify и
SoundCloud можно добавить ссылку с открытой страницы трека; полного переноса их
плейлистов пока нет. Доступ к полным записям определяет сервис и ваша подписка.
