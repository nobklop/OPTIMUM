# OPTIMUM 0.2.1 — Windows-прототип

Запустите `optimum.exe` из этой папки. Соседние DLL и папку `data` нужно сохранять
рядом с программой. Установка приложения и аккаунт не требуются.

Нажмите **«Добавить музыку»** для своих файлов или **«Послушать этюд»** для трёх
оригинальных звуковых этюдов OPTIMUM. В библиотеке можно импортировать целую папку,
искать музыку, ставить лайки и добавлять треки в собственные плейлисты.

Плеер внизу: воспроизведение/пауза, предыдущий/следующий трек, перемотка, громкость,
shuffle и repeat. Кнопка раскрытия справа открывает полный плеер и очередь.
Удаление из библиотеки оставляет исходный аудиофайл на диске.

Космический фон плавно повторяет 90-секундный цикл. Для остановки эффектов включите
**Настройки → Уменьшить движение**. При потере активности окна анимация приостанавливается.

Библиотека и настройки сохраняются локально; путь к базе показан в настройках.
В **Настройки → Сохранить копию** можно экспортировать JSON: плейлисты, избранное,
историю и настройку движения. **Восстановить из JSON** объединяет данные без удаления
текущей библиотеки. Аудиофайлы не включаются и должны оставаться по прежним путям.
Перед запуском новой версии закройте старые экземпляры OPTIMUM. При первом открытии
базы 0.1.x рядом автоматически сохраняется файл `library.db.before-v2-<время>.db`.

Это первый рабочий этап: Together, аккаунты, друзья, рекомендации и интеграции
ещё разрабатываются. Проверена Windows 11 x64; мобильные сборки пока не проверены.
