# OPTIMUM 0.4.0 — Windows-прототип

Запустите optimum.exe из этой папки; соседние DLL и data должны оставаться рядом.
Для локальной музыки аккаунт и сеть не нужны.

**Аккаунты сервисов** вверху окна (на узком экране — значок человека) открывает
Яндекс Музыку, SoundCloud или Spotify. Нажмите **Войти и открыть библиотеку**,
затем **Войти / сменить аккаунт**. Вводите данные на официальной странице сервиса.
После входа откройте **Моя библиотека**; веб-сессия сохраняется в OPTIMUM.
Выход/смена аккаунта выполняется через меню сайта. Вход через Google/Apple может
не поддерживаться сервисом во встроенном браузере. Плейлисты/лайки остаются
в сервисе до явного переноса.

В Яндексе откройте сам плейлист, **Мне нравится** или альбом и нажмите
**Перенести плейлист** над сайтом. Дождитесь проверки полного состава, подтвердите
предпросмотр. Результат находится в **Плейлисты** OPTIMUM: названия, порядок и ссылки,
включая повторы. Для непрерывного прослушивания нажмите **Открыть плейлист в сервисе**.
Повторный перенос обновляет состав после подтверждения, сохраняя ваше название.
**Добавить текущий трек** сохраняет выбранный/играющий трек. В диалоге можно
**Прикрепить аудиофайл** для офлайна — исходный файл остаётся на своём месте.
Перенос не скачивает защищённую музыку Яндекса. Для Spotify/SoundCloud добавление
работает на странице конкретного трека; полного переноса плейлистов пока нет.

**Добавить музыку** импортирует файлы; **Послушать этюд** добавляет три авторские
записи OPTIMUM. В библиотеке можно импортировать папку, искать, ставить лайки,
составлять плейлисты. Нижний плеер: play/pause, next/previous, перемотка, громкость,
shuffle/repeat. Удаление трека из библиотеки оставляет файл на диске.

**По ссылке** на главной или **Библиотека → Добавить ссылку** сохраняет публичный
трек/плейлист Spotify, Яндекс Музыки или SoundCloud без API-ключей.
**Сохранить и открыть** показывает плеер сервиса внутри OPTIMUM; сохранённые ссылки
находятся в **Библиотека → По ссылке**. Доступ, фрагмент/полная запись и вход
определяются сервисом. Обычное сохранение ссылки не переносит состав;
перенос Яндекса запускается отдельной кнопкой на странице сервиса.
Встроенный плеер требует интернет и Microsoft Edge WebView2 Runtime. При отсутствии
runtime приложение даёт ссылку на официальный установщик. Кнопка ↗ открывает сайт.
Закрытие экрана прекращает звук сервиса; перед открытием локальное аудио останавливается.

Для скачивания вставьте прямую HTTPS-ссылку на аудиофайл и нажмите **Скачать и
сохранить**. Есть прогресс и отмена, лимит 512 МБ. Файл появится среди локальных
треков для прослушивания без сети. Обычная ссылка на страницу сервисной записи
не является MP3 и не предоставляет автоматического скачивания защищённой музыки.

Космический фон плавно повторяет 90-секундный цикл; **Настройки → Уменьшить движение**
останавливает эффекты. При потере активности окна анимация приостанавливается.

База сохраняется локально, её путь показан в настройках. **Сохранить копию**
экспортирует JSON v3 со ссылками, составом сервисных плейлистов, избранным, историей
и настройкой движения. **Восстановить из JSON** объединяет данные; поддерживаются v1/v2.
Музыка не входит в JSON, сохраняйте её отдельно по прежним путям.
Перед запуском закройте старые экземпляры. До обновления v1/v2/v3 автоматически
создаётся library.db.before-v4-<время>.db. Старые версии не читают новую базу.

Together, облачные аккаунты, друзья и рекомендации ещё разрабатываются.
Проверена Windows 11 x64; мобильные сборки и их веб-плееры пока не проверены.
