# Изменения

## 0.2.2 — 2026-10-19

- Убран жёсткий ограничитель анимации 30 Гц: общий clock теперь обновляется
  на каждом кадре экрана. Кэширование туманностей и pause/reduced motion сохранены.
- Реальный Windows profile-замер: движение 30.06→69.12 обновлений/с;
  интервал p95 45.002→20.001 мс. Raster p95 15.862→15.437 мс на этом ПК.
- Отдельная проверка 120 последовательных кадров и остановки движения;
  воспроизводимый benchmark без доступа к пользовательской базе.
- Сохранён план полного импорта ссылок Яндекс Музыки / Spotify / SoundCloud;
  наличие этого плана не означает работающую интеграцию в текущем приложении.

## 0.2.1 — 2026-10-19

- Звёздный фон: 184 звезды вместо 136; пять отдельных облаков тумана по всему
  полю вместо двух крупных скоплений. Используются прежние две кэшированные текстуры.
- Главный блок: мелкие звёзды с бликами, созвездие, два спутника, дальние орбиты
  и локальная дымка. Текст и кнопки остаются читаемыми.
- Общий плавный 90-секундный период и reduced motion сохранены. Новые элементы
  включены в сравнение кадров начала/конца цикла и Windows native rendering test.
- Подготовлен общий Windows-установщик и публикация GitHub Releases с кнопкой
  скачивания каждой версии; статус проверок установки — в VERIFICATION.md.

## 0.2.0 — 2026-10-19

- Раздел резервных копий в настройках: JSON экспорт/восстановление плейлистов,
  избранного, истории и reduced motion. Аудиофайлы остаются по исходным путям.
- Атомарное объединение, валидация формата/ссылок/размера; повторное восстановление
  не дублирует данные. Текущие имена/метаданные и отметки избранного сохраняются.
- SQLite v2: устойчивые ключи плейлистов, автоматическая согласованная v1-копия
  перед обновлением. Проверены миграция, целостность копии и откат транзакции.
- Настоящая Windows codec matrix: WAV, MP3, FLAC, OGG, M4A/AAC с русскими именами
  файлов; повреждённый WAV и восстановление воспроизведения после ошибки.
- Исправлены зависание загрузки повреждённого аудио и устаревшая позиция при seek;
  таймаут загрузки 15 секунд, защита от повторного события конца записи.
- Next/previous сохраняют паузу; восстановленная история учитывает время прослушивания.

## 0.1.1 — 2026-10-19

- После замера release исправлена лишняя нагрузка Cosmic: туманности кэшируются
  в двух текстурах 256×256, частота обновления фона ограничена 30 Гц. Ввод и UI
  обновляются независимо. Бесшовный 90-секундный цикл и reduced motion сохранены.

## 0.1.0 — 2026-10-19

Первый самостоятельный локальный Windows-прототип OPTIMUM.

- Flutter 3.47.7: Windows/Android/iOS runners, собственный шрифт и launcher mark.
- Cosmic: 136 звёзд в трёх слоях, мерцание, shader-туманности, параллакс,
  движущиеся орбиты и спутник. Единый 90-секундный периодический цикл без скачка;
  проверка совпадения кадров t=0 и t=90. Reduced motion и остановка при неактивном окне.
- Настоящий локальный аудиоплеер, сериализованная загрузка, очередь, repeat/shuffle,
  встроенные обложки, обработка пропавших файлов без возобновления старой записи.
- SQLite: импорт, метаданные в isolate, поиск, likes, история реального прослушивания,
  плейлисты; удаление записей не затрагивает файлы музыки.
- Три оригинальных звуковых этюда и воспроизводимый генератор.
- FastAPI health/capabilities и тестируемый авторитетный домен Together.
- Исправлены обнаруженные гонки refresh/закрытия базы, переполнения sidebar,
  stale favourite state и удаление треков из активной очереди.
- Локальный compatibility patch just_audio_media_kit устраняет ошибки OSC/disk cache
  на audio-only Windows backend; исходная лицензия и описание изменений сохранены.
- Документация на русском, lockfiles, тесты, скрипты проверок/упаковки, Git checkpoint.

Аккаунты/Supabase, сетевые комнаты, социальные функции, рекомендации, интеграции,
серверная генерация подборок и мобильный фон ещё не реализованы.
